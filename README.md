# Умная школа AI

Мобильное веб-приложение — учебный помощник для ребёнка, который учится в 4-м классе. Оно работает как обычный сайт, а на iPhone его можно добавить на экран «Домой» и открывать почти как отдельное приложение.

## Что уже работает

- выбор учебного предмета и режима обучения;
- текстовые вопросы учителю;
- распознавание голосового вопроса, если браузер поддерживает Web Speech API;
- озвучивание ответа на русском языке;
- несколько безопасных демонстрационных объяснений без внешнего ИИ;
- установка как PWA и базовая работа офлайн.

## Запуск на компьютере

Для работы микрофона и PWA страницу нужно открывать через локальный веб-сервер, а не двойным кликом по `index.html`.

```bash
python3 -m http.server 8000
```

Затем открыть `http://localhost:8000`.

## Публикация на GitHub Pages

1. Создать публичный репозиторий, например `umnaya-shkola-ai`.
2. Загрузить содержимое этой папки в ветку `main`.
3. В GitHub открыть **Settings → Pages**.
4. В разделе **Build and deployment → Source** выбрать **GitHub Actions**.
5. Дождаться завершения задачи **Publish GitHub Pages** во вкладке **Actions**.

Адрес будет иметь вид: `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/umnaya-shkola-ai/`.

## Добавление на iPhone

1. Открыть опубликованный HTTPS-адрес в Safari.
2. Нажать кнопку «Поделиться».
3. Выбрать «На экран “Домой”».
4. Подтвердить название «Моя школа».

Для голосового ввода нужно разрешить сайту доступ к микрофону. Поддержка распознавания речи зависит от версии iOS/Safari; текстовый ввод и озвучивание остаются запасным вариантом.

## Важно о настоящем голосовом ИИ

Эта версия не отправляет данные ребёнка во внешний ИИ и не содержит API-ключей. Для свободного диалога нужен отдельный защищённый backend, который:

- хранит API-ключ только в секретах сервера;
- принимает запросы приложения по HTTPS;
- ограничивает расходы, частоту запросов и длину диалога;
- фильтрует небезопасный контент и не собирает лишние данные ребёнка;
- передаёт браузеру только необходимый результат.

Никогда не помещайте API-ключ в `app.js`, HTML, публичный репозиторий или настройки GitHub Pages: любой посетитель сможет его увидеть и использовать.

GitHub Pages публикует только статические файлы и не заменяет такой backend. Позже его можно разместить отдельно (например, как serverless-функцию), а адрес backend указать в приложении.
